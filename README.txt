Aevum 分野の並べ替え更新版 v1.3

GitHubの aevum リポジトリ直下に index.html を上書きしてください。
川の動画・画像・アイコンなどは前のままで使えます。
念のため、更新前にアプリの「設定・保存」からバックアップを書き出してください。

設定・保存 → 自分だけの分野 の ↑ ↓ ボタンで並べ替えできます。
順番は自動保存され、記録画面・グラフの凡例・日記内の分野表示・スライドの分野選択にも反映されます。
過去の日記・画像・数値や編集中の内容は変更しません。
同じ端末・ブラウザ・公開URLでお使いください。

確認：構文、上下移動、端の移動防止、既存記録を変更しないこと。
iPhone実機でのタップと更新後の表示は未確認です。
