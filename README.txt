Aevum（アエウム） 川の動画背景版 v1.2
日々のしずくが、わたしの川になる。

GitHub Pagesで使う手順
1. GitHubで新しいリポジトリを作成（例：life-chart）。
2. このフォルダ内の index.html、icon.svg、apple-touch-icon.png、manifest.webmanifest、river.mp4、river-poster.jpg、.nojekyll をリポジトリ直下にアップロード。
3. Settings → Pages → Deploy from a branch → main / (root) → Save。
4. 表示された公開URLをSafariで開く。共有メニューから「ホーム画面に追加」もできます。
ZIPそのものをGitHubに置くのではなく、展開した中身を置いてください。

使い方
「記録する」で分野ごとの変化を−3〜＋3で選択。未選択と0は区別されます。
1日1件。保存後の修正は「思い出す」の編集から。
グラフは「積み重ね」と「その日のプラマイ」を切り替え可能。
記録しない日は空白。昨日との差を記録する仕様のため、未記録日の変化は合計に含まれません。
写真・ファイル・手入力の場所・現在地を添付できます。
グラフ上の点を押すと日記が開きます。
プラス／マイナスの日の写真を自動でスライド上映できます（動画書き出しは未実装）。
サンプルは自分の記録と別で、保存やバックアップには入りません。

データについて
日記と添付はブラウザ内のIndexedDBに保存。サーバーへの日記送信や自動同期はありません。
GitHubにはアプリ本体だけを置いてください。
端末・ブラウザ・公開URLが変わると別の保存領域になります。
プライベートブラウズでは記録が消える場合があるため通常モードで使用してください。
定期的に「設定・保存」からバックアップを書き出してください。
読み込みは記録全体を置き換えるので、先に現在のバックアップを保存してください。
写真はJPEGに縮小。その他の添付は1件10MBまで。
現在地は許可したときだけ取得。地図リンクを開くとOpenStreetMapに移動します。

確認済み：JavaScript構文、グラフ集計、未記録間隔、検索、読み込みデータの基本検証。
未確認：iPhone実機での表示、画像選択、位置情報許可、保存・復元の一連の操作。

背景動画について
無音・ループ・インライン再生。右上から停止・再生できます。
iPhoneの省電力モードなどで自動再生されない場合は、静止画が表示されます。
「背景を再生」で再生を試せます。端末の動きを減らす設定では初期状態で停止します。
動画・静止画は同梱済み。別サイトからの動画読み込みはありません。
前版と同じGitHub公開URLに上書きすれば、端末内の日記の保存領域は変わりません。
更新前に念のためバックアップを書き出してください。
